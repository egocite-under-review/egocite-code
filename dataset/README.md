# dataset/

Everything EgoCITE reads as input. Nothing here is generated by the pipeline —
all generated content goes to `output/`.

`src/config.py` points at this directory (`DATASET_DIR`), and each benchmark has
its own root so you can move one without moving the rest:

| Config | Directory | Used by |
|---|---|---|
| `EGOLIFE_DATASET` | `EgoLife/` | `src/preprocess/` — SRTs and video |
| `EGOLIFEQA_DATASET` | `Ego-R1-Data/` | `src/eval/eval_egolifeqa.py` |
| `EGOR1_DATASET` | `Ego-R1-Bench/` | `src/eval/eval_egor1.py` |
| `EGOMEM_DATASET` | `LifeDialBench/` | `src/eval/eval_egomem.py` |

Fetch the first three with `bash src/scripts/0-download.sh`.

## EgoLife — `EgoLife/`

<https://huggingface.co/datasets/lmms-lab/EgoLife>

The raw release: `EgoLifeCap/DenseCaption/{person}/DAYn/*.srt`,
`EgoLifeCap/Transcript/{person}/DAYn/*.srt`, and the video clips at
`{person}/DAYn/*.mp4`. Read-only input to preprocessing.

## EgoLifeQA — `Ego-R1-Data/`

<https://huggingface.co/datasets/Ego-R1/Ego-R1-Data>

Questions at `Ego-QA-4.4K/manual-2.9K/{person}.json` — 2,905 multiple-choice
questions over the six wearers.

## Ego-R1-Bench — `Ego-R1-Bench/`

<https://huggingface.co/datasets/Ego-R1/Ego-R1-Bench>

Two splits: `manual-benchmark/{person}.json` and `gemini-benchmark/{person}.json`.
`3-eval.sh --bench egor1` runs both.

## EgoMem — `LifeDialBench/`

<https://github.com/RayNeo-AI-2025/LifeDialBench>

Cloned from the upstream repo. The file the eval actually reads,
`data/EgoMem-Normalized.json`, is **derived**, not upstream: it is the released
EgoMem data converted into the EgoLifeQA convention by

    python src/preprocess/normalize_egomem.py

which rewrites the wearer's name to first person ("Alice went…" → "I went…"),
maps calendar dates to `DAY1..DAY8`, converts `HH:MM` to the `HHMMSSFF` integer
format the memory uses, and turns `question_time` / `evidence_date` into the
`{date, start_time, end_time}` structures the harness expects.

Schema: a list of 6 entries (one per wearer), each
`{history_name, chat_time, chat_history, qa}`.

Regenerate it only if the upstream data changes — normalization calls an LLM for
the name rewriting, so it is not free and the committed output is the reference.
